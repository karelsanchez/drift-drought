Changelog
=========

0.1.1 (2026-11-21)
------------------

Documentation: metrics (equations and interpretation), tests and validation, gallery, mini benchmark. Bundled library
of 99 real drought shapes (:func:`driftdrought.synthetic.example_library`). CI actions updated.

0.1.0 (2026-11-20)
------------------

First release: DRIFT detection (volume-weighted persistence, noise-adaptive threshold, lineage inheritance, birth and
watershed footprints), floor selection, event tables, drought indices, synthetic benchmark (Gaussian and irregular
events), reference detectors, HOTA and object metrics, event confidence and surrogate significance. The labels are
identical to those of the implementation used in the DRIFT paper.
