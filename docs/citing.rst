Citing DRIFT
============

If you use DRIFT, please cite the software (the version DOI from Zenodo) and the article:

   Sanchez H., K. A. (2026). DRIFT for detecting and tracking spatiotemporal drought events with component trees.
   *Water Resources Research* (submitted).

The ``CITATION.cff`` file in the repository gives the citation in machine-readable form; GitHub shows it under
"Cite this repository".
